\# 실패 사례집 (코드 작성 전 반드시 확인)



각 항목은 "증상이 없거나 늦게 나타나는" 버그들이다.

컴파일 에러나 예외로 드러나는 문제는 여기 없다.



\## P-01  MarketEye/StockChart 필드 순서 뒤섞임  \[치명 / 무증상]



증상   : 예외 없음. 거래대금 자리에 시가가 들어가 백테스트 성과가 이상해짐

원인   : 응답 필드가 "요청 필드번호 오름차순"으로 정렬되는데 요청 배열

&#x20;        순서로 인덱싱함

탐지   : T02 테스트 — 필드를 무작위 순서로 요청해도 HTS \[7059]와 값 일치

방지   : sorted(fields) 기반 {field\_no: index} 맵 강제. 원시 인덱스 접근 금지



\## P-02  pyarrow 32-bit 휠 없음  \[빌드 실패 / 중반 발견]



증상   : P1 에 Parquet 저장 기능을 붙이는 순간 pip install 실패

원인   : pyarrow 는 Windows 32-bit 휠 미제공

방지   : INV-01. P1 허용 패키지 화이트리스트를 requirements-32.txt 로 고정.

&#x20;        직렬화는 msgpack + numpy 원시배열만



\## P-03  무수정주가로 백테스트  \[치명 / 무증상]



증상   : 액면분할/무상증자 종목에서 가짜 갭이 급등 신호로 잡혀 성과 과대

원인   : StockChart 입력 type 9 기본값이 '0'(무수정)

방지   : INV-08. 항상 '1'. T04 테스트로 분할 종목 연속성 확인



\## P-04  미래정보 누수 (종가 확정값으로 종가 진입)  \[치명 / 실전에서만 발현]



증상   : 백테스트 Sharpe 2.0, 실전 0.3

원인   : 15:10 스캔인데 당일 확정 종가/거래대금으로 필터링

방지   : INV-05. 모드 A/B 동시 산출, 공식 성과는 B, B/A >= 0.70 게이트(T06)

&#x20;        15:10 시점 close 프록시와 거래대금 보정계수(1.06)는 실전/백테스트

&#x20;        동일 코드 경로



\## P-05  StockCur 누적거래대금 단위 혼용  \[무증상]



증상   : 위성 전략의 거래대금 배수(MV)가 시장별로 10\~100배 차이

원인   : StockCur 헤더 10 은 거래소 '만원', 코스닥 '천원'.

&#x20;        MarketEye 필드 11 은 '원'

방지   : 레이크 표준 '원'. StockCur 값에 시장별 승수 적용하는 정규화 함수

&#x20;        단일 지점 통과. V-C05 로 실측 확인



\## P-06  Creon 요청 제한 초과  \[세션 사망]



증상   : 조회가 멈추거나 세션 재시작 필요. 개발 중 하루 손실

원인   : 15초/60건 초과

방지   : INV-03. RateGovernor 를 1주차에 먼저 만든다.

&#x20;        나중에 붙이면 개발 중에 반드시 걸린다



\## P-07  COM 멀티스레드 접근  \[간헐 크래시 / 재현 불가]



증상   : 무작위 시점에 P1 프로세스 죽음. 스택 트레이스 무의미

원인   : COM STA 객체를 다른 스레드에서 호출

방지   : INV-04. 단일 스레드 + CoInitialize + PumpWaitingMessages 루프.

&#x20;        RPC 핸들러는 큐에 넣기만 하고 실행은 COM 스레드에서



\## P-08  주문 중복 체결  \[실손실]



증상   : 의도 1건인데 2건 체결

원인   : 타임아웃 후 조회 없이 재시도

방지   : INV-09. intent\_id 멱등키 + 재시도 전 미체결/체결 조회.

&#x20;        T12 테스트(동일 intent 100회 → 실주문 1건)



\## P-09  P1 사망 시 전략이 stale 데이터로 계속 매매  \[실손실]



증상   : 시세가 멈춘 상태로 주문 발생

원인   : 데이터 소스 장애를 전략이 인지하지 못함

방지   : OnDisConnect / IsConnect==0 → PUB 브로드캐스트 →

&#x20;        P2 가 레짐 RED 강제 전환 + 신규 진입 차단. T11 장애 주입 테스트



\## P-10  Creon/키움 가격 불일치  \[무증상 → 실손실]



증상   : Creon 기준으로 계산한 지정가가 키움에서 거부되거나 크게 불리하게 체결

원인   : 데이터와 주문이 다른 증권사. 종목코드 표기도 다름

방지   : 매일 15:40 reconcile 잡. 보유 종목의 Creon 종가 vs 키움 0B 마지막

&#x20;        체결가 비교. 괴리 0.1% 초과 시 경보 + 익일 신규 진입 차단.

&#x20;        종목코드 변환은 INV-10 단일 함수



\## P-11  종가 동시호가 지정가 오해  \[체결 실패 또는 불리한 체결]



증상   : 종가 진입이 아예 안 되거나 예상보다 비싸게 체결

원인   : 15:20\~15:30 은 단일가 체결. 지정가를 종가보다 높게 내면 종가에

&#x20;        체결되고, 낮게 내면 미체결

방지   : 예상체결가(필드28) x 1.005 지정가. 15:26 재조회 후 필요 시

&#x20;        정정(kt10002). 15:28 이후 정정 금지



\## P-12  KRX 반일장/휴장 미반영  \[오동작]



증상   : 휴장일에 스케줄러가 돌거나 반일장에 15:10 스캔이 실패

원인   : 거래 캘린더 부재

방지   : KRX 캘린더 모듈. GetMarketStartTime/GetMarketEndTime 보조 확인.

&#x20;        타임존은 Asia/Seoul 고정



\## P-13  분봉 페이징 무한루프 또는 누락  \[데이터 손상]



증상   : 봉 개수가 예상과 다름. 중복 또는 구멍

원인   : 2,499개 상한과 요청종료일 밀기 로직 오류

방지   : 헤더 3(수신개수)==0 종료 조건 + (날짜,시간) dedup.

&#x20;        T03 테스트(거래일수 x 381 ± 5, 중복 0)



\## P-14  과최적화  \[백테스트만 좋음]



증상   : OOS 성과가 IS의 30% 이하

원인   : 729조합 그리드에서 최적값 채택

방지   : 2단계 탐색(27조합 → 나머지). 채택 기준은 최적값이 아니라

&#x20;        평탄성(plateau). 인접 조합 Sharpe 30% 이상 급락 시 폐기.

&#x20;        레짐 파라미터는 MDD 최소화로만 튜닝, 수익률로 튜닝 금지



\## P-15  생존편향  \[성과 과대]



증상   : 백테스트 CAGR 과대

원인   : 현재 상장 종목만으로 과거 유니버스 구성

방지   : universe\_meta 를 매일 스냅샷(비소모 여부 V-C12 검증 전 거버너 경유)하고 날짜 조인.

&#x20;        상폐 종목은 -70% 또는 정리매매 실제가. T05 테스트



\## P-16  거래비용 과소 반영  \[전략 자체가 무의미해짐]



증상   : 백테스트 흑자, 실전 적자

원인   : 2026-01-01 부터 증권거래세 환원 (코스피 0.05%+농특세 0.15%=0.2%,

&#x20;        코스닥 0.2%). 왕복 실비용 0.35\~0.50%

방지   : 거래당 평균 총수익 >= 왕복비용 x 1.5 (G3). 비용 2배 스트레스(G4).

&#x20;        이것이 고회전 전략을 구조적으로 배제하는 근거

## P-27 실시간 틱 필터링

StockCur 체결 틱은 유량 정책에 따라 누락될 수 있다. 거래대금·거래량 게이트는 MarketEye 누적값의 5초 차분만 사용하고, StockCur는 최신 가격 포착에 한정한다. 30분 교차검증 괴리가 5% 이상이면 실패로 기록한다(T28).
